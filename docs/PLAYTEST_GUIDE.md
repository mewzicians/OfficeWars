# Human Playtest Guide

Human playtests should capture decisions and enjoyment that scripted policies
cannot model.

## Minimal Run Record

- game hash or release tag;
- result and final floor;
- loss cause, if any;
- first trait path and final trait paths;
- capstone;
- memorable cards and Home upgrades;
- whether the run felt decided too early or too late;
- any confusing card, tracker, tooltip, or decision surface.

## Closing Focus

For a Sales Cycle, also record:

- floor and project state when the Hot Lead was selected;
- stress, days left, and Chad progress when the Cycle began;
- actual Chain at Close;
- Close reward offered and selected;
- whether the player would make the same cash-out decision again;
- outcome and primary loss cause after the Close.

The central question is not merely whether Chain 9 wins. It is whether surviving
the risk makes the player feel heavily favored while leaving meaningful play.

## Reporting

Use the GitHub balance-feedback issue template. Several ordinary runs are more
useful than one unusually lucky or unlucky story, though exceptional stories
are valuable for finding broken interactions.
