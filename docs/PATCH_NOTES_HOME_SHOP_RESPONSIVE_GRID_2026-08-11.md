# OfficeWars Responsive Home Shop Grid

Release date: 2026-08-11

## Player-Facing Changes

- Three Home Shop offers now expand across the usable iPad width instead of
  remaining narrow cards surrounded by empty space.
- A fourth visible Home offer automatically switches the row to four equal
  columns.
- Compact landscape styling keeps all offers, Home purchase actions, and the
  persistent Night footer visible together.

## Compatibility

- Home offer generation, prices, purchase limits, rerolls, and balance values
  are unchanged.
- Active-run and tutorial save schemas are unchanged.
