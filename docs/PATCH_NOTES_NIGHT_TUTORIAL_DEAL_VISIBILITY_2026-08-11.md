# OfficeWars Focused Night Tutorial And Deal Visibility

Release date: 2026-08-11

## Player-Facing Changes

- The Night tutorial is split into four short, focused lessons for Home Shop,
  Outings, Relationships, and recovery/finalization.
- Each lesson automatically opens its matching Night Planner tab before
  spotlighting the relevant controls.
- Deal Desk is hidden until Sales or another active effect provides a legal
  Deal purchase. It returns as a fourth Planner tab when access is available.
- Home and Deal item groups are centered in the usable iPad content area on
  desktop and compact landscape screens.

## Compatibility

- The meta save schema is now version 5.
- Schema-4 tutorial progress migrates into the thirteen-step sequence without
  replaying completed onboarding.
- Older supported meta schemas continue through their existing migrations.
- Active-run saves and gameplay balance values are unchanged.
