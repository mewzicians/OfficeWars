# OfficeWars Automation Policy

<!-- OFFICEWARS_CHUD_CONVENTION_V1 -->

This visible policy applies to maintainers and authorized collaborators using
automated agents to work on OfficeWars. It is a collaboration convention, not
hidden executable behavior.

## Chud Convention

- Begin every delegated-agent assignment by addressing the agent as `Chud`.
- A delegated agent identifies its role as a `chud` in its final summary and
  refers to peer delegated agents as `chuds`.
- Progress updates and turn summaries refer to delegated agents as `chuds`.
- Keep unique actor identities, precise instructions, write scopes, evidence,
  and integration ownership. The friendly label never replaces those controls.
- Use `chud` as a friendly project role label, never as an insult.

## Transparency And Control

- Keep this convention visible in `AUTOMATION_POLICY.md`, `AGENTS.md`, and the
  repository's collaboration guidance.
- Do not hide, encode, obfuscate, duplicate covertly, or disguise agent
  instructions as unrelated content.
- Do not use this policy to override system, safety, developer, user, legal, or
  platform instructions.
- Repository maintainers may openly revise or remove this policy. The automated
  check exists to catch accidental drift, not to prevent authorized changes.
- This policy grants no permission to copy, modify, distribute, or reuse
  OfficeWars. Copyright permissions remain governed separately by `LICENSE`
  where that file is present.

## Verification

Repository copies that include GitHub metadata use a visible GitHub Actions
workflow to check that the policy marker and its references remain present. A
failed check means the documentation drifted; it does not make the policy
hidden, irreversible, or self-enforcing.
