# Choose A License Before Inviting Reuse

This snapshot intentionally does not choose legal terms on the project owner's
behalf. Publishing without a `LICENSE` file allows people to view the source,
but generally does not grant permission to copy, modify, or redistribute it.

Common choices:

- **MIT**: short and permissive; a practical choice when broad reuse is welcome.
- **Apache-2.0**: permissive with explicit patent language.
- **GPL-3.0**: requires redistributed modifications to remain open source under
  the same license.

GitHub can add a standard license without Git:

1. Select **Add file**, then **Create new file**.
2. Name it `LICENSE`.
3. Select **Choose a license template**.
4. Review the owner name and year.
5. Commit the file.

Do not copy a license from another game or use a Creative Commons license for
the gameplay code without understanding the consequences. If art, writing, and
code need different terms, document that explicitly.

This guide is not legal advice.
